# Цифровой старт 

Сайт для информирования и принятия заявок на конференции студенческих IT-проектов «Цифровой старт» в Вологде.

## Назначение проекта

Разработан как информационный лендинг для конференции и предназначен для публикации информации о мероприятии и привлечения участников.

Вёрстка с требованиями стандартной структуры, базовым стеком для дальнейшего поддерживания начинающими разработчиками и полной адаптивности. 

## О проекте

«Цифровой старт» — конференция студенческих IT-проектов для обучающихся IT-специальностей среднего профессионального образования или энтузиаствов с опытом.

На сайте реализованы:

- дизайн и стилизация по требованиям;
- полностью ручная вёрстка;
- полная адаптивность;
- навигация по разделам страницы;
- компактное размещение отобранной информации;
- форма подачи заявки;
- ссылка на положение о конференции;
- различные карточки экспертов;
- таймер окончания приёма заявок;
- интерактивная карта места проведения;
- анимации элементов интерфейса.

> Работа велась в сотрудничестве с дизайнером от клиента.

## Структура проекта

`static/` - основная директория.

> `static/pictures/` - изображения и графические материалы.

> `static/styles/` - стили и анимации.

> `static/documents/` - документы, используемые на сайте.

`js/` - директория с .js файлами.

> `js/animations.js` - анимации элементов страницы.

> `js/time.js` - таймер оставшегося времени подачи заявок.

`index.html` - основная страница.

## Технологии

- CSS;
- JavaScript;
- ЯндексКарты API.
